# Shikimori для Lampa

Плагин аниме-каталога Shikimori для [Lampa](https://lampa.mx): списки пользователя, каталог с фильтрами, поиск, просмотр с озвучками, отметка просмотренных серий и прогресс в профиле Shikimori.

## Установка

1. Откройте Lampa → **Настройки → Расширения → Добавить плагин**.
2. Вставьте URL:
   ```
   https://gtds-page.github.io/lampa-shikimori/shikimori.js
   ```
3. Перезапустите Lampa.

После установки в главном меню появятся **Shikimori**, **Каталог аниме** и **Поиск аниме**.

## Вход

Вход выполняется **по QR-коду**, без ввода пароля и токена с пульта:

1. **Настройки → Shikimori → Вход по QR-коду**.
2. Отсканируйте QR телефоном.
3. Войдите в Shikimori и разрешите доступ.
4. Телевизор сам получит токен и подтянет списки.

Токен хранится локально в Lampa. `access_token` живёт около суток, `refresh_token` — около года. Плагин обновляет access-токен через relay при запуске Lampa и автоматически повторяет запрос, если Shikimori ответил 401. Постоянного токена у Shikimori нет; если refresh-токен отозван или истёк, нужен повторный вход по QR.

Для продвинутых пользователей остаётся ручной ввод `access_token` в настройках — если QR недоступен.

## Возможности

- Списки «Смотрю», «В планах», «Просмотрено», «Отложено», «Пересматриваю».
- Каталог Shikimori с фильтрами (популярность, рейтинг, год, жанр, статус).
- Поиск по названию.
- Карточка аниме: описание, озвучки, серии, статус просмотра.
- Запуск видео через Kodik/AniLibria во внешнем плеере Lampa.
- Автоматическая отметка серий в профиле Shikimori (порог настраивается).
- Интерфейс рассчитан на управление пультом (D-pad), с горизонтальными рядами и ленивой загрузкой постеров.

## Данные и приватность

- Профиль, списки и прогресс — через официальный API `https://shikimori.io`.
- Видео — через сторонние источники Kodik и AniLibria.
- Для OAuth используется relay `https://vechwzycaplsjabenhuz.supabase.co/functions/v1/shikimori-auth`: он только обменивает одноразовый код на токен и возвращает его на телевизор. Пароль Shikimori плагину не передаётся.
- Плагин не содержит аналитики и не отправляет данные третьим лицам, кроме перечисленных сервисов.
- Токен и настройки хранятся в локальном хранилище Lampa на устройстве.

## Ограничения

- Нужен аккаунт Shikimori для списков и синхронизации; без входа доступен каталог и поиск.
- Для входа по QR нужен доступ к relay по HTTPS.
- Токены Kodik — сторонние API-ключи, они могут перестать работать; в этом случае используется AniLibria.

## Сборка

```bash
node build.js   # соберёт dist/shikimori.js из src/
```

## Серверная часть

Relay для OAuth находится в `server/`. Инструкция по развёртыванию — `server/README.md`. Секреты (`client_id`, `client_secret`) хранятся только в `config.json` на сервере и **не входят** в плагин.
