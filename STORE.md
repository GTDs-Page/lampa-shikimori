# Shikimori — описание для магазина

## Короткое (до 80 символов)

Аниме из Shikimori: списки, каталог, поиск и просмотр с озвучками.

## Короткое (до 160 символов)

Плагин Shikimori для Lampa: ваши списки, каталог с фильтрами, поиск, просмотр с озвучками и автоотметка серий. Вход по QR-коду, управление пультом.

## Полное

Shikimori для Lampa — это аниме-каталог и ваши списки прямо на телевизоре.

Возможности:
- списки «Смотрю», «В планах», «Просмотрено», «Отложено», «Пересматриваю»;
- каталог Shikimori с фильтрами по популярности, рейтингу, году, жанру и статусу;
- поиск по названию;
- карточка аниме с описанием, озвучками и сериями;
- запуск видео через Kodik/AniLibria во внешнем плеере Lampa;
- автоматическая отметка просмотренных серий в профиле Shikimori;
- вход по QR-коду с телефона — не нужно вводить пароль или токен пультом;
- интерфейс полностью рассчитан на D-pad и пульт.

Данные:
- профиль, списки и прогресс — через официальный API Shikimori (shikimori.io);
- видео — сторонние источники Kodik и AniLibria;
- OAuth — через relay, который обменивает одноразовый код на токен; пароль Shikimori плагину не передаётся;
- токен и настройки хранятся только на устройстве.

Требования: Lampa 2.x, Android TV или ТВ-приставка, интернет. Для списков и синхронизации нужен аккаунт Shikimori.

## Исходники и лицензия

MIT. Серверная часть для OAuth — в папке `server/` (без секретов; `client_id`/`client_secret` задаются в `config.json` на сервере).

## Примечания для модерации

- Плагин не содержит встроенных OAuth-секретов: `client_id` и `client_secret` хранятся только на сервере relay.
- Каждый пользователь получает собственный токен Shikimori через OAuth; общих токенов нет.
- Плагин не собирает аналитику и не передаёт данные, кроме запросов к Shikimori, Kodik и AniLibria.
